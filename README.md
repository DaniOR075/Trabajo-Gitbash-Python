# Cuentas Claras

Cuentas Claras. Esta aplicación ayudará a llevar el control de los fiados realizados en una tienda, permitiendo registrar las deudas de los clientes, consultar los saldos pendientes y mantener un historial de los productos o compras fiadas y los pagos realizados. Su objetivo es facilitar la administración de las cuentas por cobrar, mantener la información organizada y mejorar el seguimiento de las deudas de cada cliente.
